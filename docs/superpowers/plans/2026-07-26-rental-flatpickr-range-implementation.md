# Rental Flatpickr Range Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Rental's two native start/end datetime controls with one combined Flatpickr date-time range picker.

**Architecture:** Add one small `RentalDateRangePicker` wrapper that owns Flatpickr's imperative lifecycle. Keep Rental's existing business state (`rentalTimeRange`, `rentalStartAt`, `rentalEndAt`, `duration`, validation, draft, checkout) unchanged except for the input adapter. Replace mobile and desktop duplicate datetime controls with the same render helper.

**Tech Stack:** React 19, Vite, Flatpickr, Vitest, Testing Library.

## Global Constraints

- Use one combined date-time range input in Rental's "Rentang Waktu Sewa" card.
- Flatpickr options must include `mode: "range"`, `enableTime: true`, 24-hour time, and `minuteIncrement: 15`.
- Existing checkout payload shape, pricing rules, draft persistence format, duration calculation, and validation messages remain unchanged.
- Styling must follow the current solid white and green theme with small radii, no blur/glass effect, and no legacy orange styling.
- Tests must mock Flatpickr for focused picker behavior.

- [ ] **Step 3: Implement the component**

Create `apps/web/src/components/RentalDateRangePicker.jsx`:

```jsx
import React, { useEffect, useRef } from 'react';
import flatpickr from 'flatpickr';
import 'flatpickr/dist/flatpickr.css';

const padDatePart = (value) => String(value).padStart(2, '0');

const formatDateTimeLocalValue = (date) => {
  if (!(date instanceof Date) || Number.isNaN(date.getTime())) {
    return '';
  }

  const year = date.getFullYear();
  const month = padDatePart(date.getMonth() + 1);
  const day = padDatePart(date.getDate());
  const hours = padDatePart(date.getHours());
  const minutes = padDatePart(date.getMinutes());
  return `${year}-${month}-${day}T${hours}:${minutes}`;
};

const RentalDateRangePicker = ({
  startAt = '',
  endAt = '',
  onChange,
  className = '',
  error = false,
  fieldKey = 'shared-rentalRange',
  describedBy,
}) => {
  const inputRef = useRef(null);
  const pickerRef = useRef(null);
  const onChangeRef = useRef(onChange);

  useEffect(() => {
    onChangeRef.current = onChange;
  }, [onChange]);

  useEffect(() => {
    if (!inputRef.current) {
      return undefined;
    }

    pickerRef.current = flatpickr(inputRef.current, {
      mode: 'range',
      enableTime: true,
      time_24hr: true,
      minuteIncrement: 15,
      dateFormat: 'Y-m-d\\TH:i',
      altInput: true,
      altFormat: 'd M Y H:i',
      allowInput: true,
      disableMobile: true,
      onChange: (selectedDates) => {
        const [startDate, endDate] = selectedDates;
        onChangeRef.current?.(
          formatDateTimeLocalValue(startDate),
          formatDateTimeLocalValue(endDate),
        );
      },
    });

    return () => {
      pickerRef.current?.destroy();
      pickerRef.current = null;
    };
  }, []);

  useEffect(() => {
    pickerRef.current?.setDate([startAt, endAt].filter(Boolean), false);
  }, [startAt, endAt]);

  return (
    <input
      ref={inputRef}
      className={`${className} rental-date-range-input ${error ? 'border-[#c0392b]' : ''}`.trim()}
      type="text"
      data-rental-field={fieldKey}
      aria-invalid={error}
      aria-describedby={describedBy}
      placeholder="Pilih tanggal & jam mulai - selesai"
    />
  );
};

export default RentalDateRangePicker;
```
